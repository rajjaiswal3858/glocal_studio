# Glocal Studio
Glocal Studio

Minimum Requirement:
- Node 20
- NPM
- React v18
- Express v5

Setup:
- Install packages using the `npm ci` command

Run:
- To run, use the `npm run dev` command in the terminal.
- Hit `http://localhost:3000/` to preview the local server.

Build:
- To generate build run `npm run build` command in terminal.
- The build will be generated and stored in the `build` folder.

Depoy:
- To deploy to the server, you need to set up the Vercel CLI tool locally.

Enjoy!!!
